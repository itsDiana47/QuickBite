# QuickBite

A food ordering website with an interactive menu, shopping cart, and order processing.

## Features

- Browse food menu
- Add items to cart
- Update cart quantities
- View order total
- Contact form

## Technologies

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## How to Run Locally

1. Install XAMPP.
2. Place the project inside the `htdocs` folder.
3. Start Apache and MySQL.
4. Create the `quickbite` database.
5. Open the project through:
   `http://localhost/quickbite/`
